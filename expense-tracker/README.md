# Expense Tracker

A REST API for personal expense tracking with user authentication.

## Features
- User registration and login
- Add, view, edit, delete expenses
- Filter expenses by category and date

## Setup

1. Install dependencies: npm install
2. Create MySQL database: expense_tracker
3. Configure database credentials in server.js
4. Run the server: node server.js

## API Endpoints

GET /api/test - Test route
GET /api/users - Get all users
POST /api/auth/register - Register a new user (coming Week 4)
POST /api/auth/login - Login (coming Week 4)
